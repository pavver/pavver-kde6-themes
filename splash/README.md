# Заставка запуску Pavver

Екран запуску Plasma, який показується між входом через SDDM і появою робочого столу.
Він використовує той самий `LoginLoader.qml`, що й екран входу, тому перехід до робочого столу залишається суцільним.

## Системні вимоги

- KDE Plasma 6.
- QML-модулі `QtQuick`, `QtQuick.Shapes` і `Qt5Compat.GraphicalEffects`.

## Встановлення

Заставка вибирається окремо для кожного користувача, тому активація виконується без `sudo`:

```bash
./install.sh --activate
```

Без `--activate` файли лише встановлюються, а заставку можна вибрати в Системних параметрах у розділі «Заставка».
Глобальна тема при цьому не змінюється.

## Перевірка

```bash
ksplashqml --test --window pavver-splash
```
